# Privacy Policy

Last updated: July 27, 2026

## Summary

Newest for YouTube is an unpacked, personal-use Chrome extension. It does not run a backend service, use analytics, sell data, or transmit data to the developer.

## Information handled by the extension

The extension stores the YouTube Data API key that you provide in Chrome's local extension storage on your device. The key is used only to request public YouTube video-search results directly from Google's YouTube Data API.

When you use the extension on a YouTube search-results page, the extension reads the search term from that page and sends it, together with your API key, directly to Google's YouTube Data API to request newest-first public video results.

## Data sharing and retention

The extension does not send your API key, search terms, browsing history, or other personal information to the developer or to any third-party server operated by the developer. The extension does not retain search history. You can remove the saved API key at any time by clearing the extension's local data or uninstalling the extension.

Google's handling of requests made to the YouTube Data API is governed by the [Google Privacy Policy](https://policies.google.com/privacy) and the [YouTube Terms of Service](https://www.youtube.com/t/terms).
